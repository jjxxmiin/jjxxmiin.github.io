# OPSOAI 키워드 뱅크

구글과 네이버 자동완성에서 수집한 **실제 검색어** 1,788개 기반. 원본은
`automation/data/keyword_bank.json`, 수집기는 `automation/harvest_keywords.py`
(수집일 2026-08-23, 요청 2,208건).

자동완성은 절대 검색량을 주지 않는다. 알 수 있는 건 "아무도 안 치는 말은
아니다"는 것과 상대적 우선순위뿐이다. 그래도 상상해서 적은 키워드보다는
훨씬 낫다 — 612편을 쓰고 하루 검색 세션 4.4를 얻은 게 상상으로 쓴 결과다.

**신뢰도 표기**: `G+N`은 구글과 네이버 양쪽 자동완성에 모두 뜬 것(1,788개 중
126개뿐). 가장 확실한 수요 신호다. `G`/`N`은 한쪽에서만 나온 것.

---

## 데이터가 뒤집은 것

초안 기획서는 "Ring 1(직장인 실무)으로 옮겨가라"였다. 데이터는 **그 전에 할
게 있다**고 말한다.

| 이미 쓴 글 | 편수 | 그 주제의 검색어 변형 수 |
| --- | --- | --- |
| ClaudeCode | 68편 | `클로드 코드` **213개** |
| AI코딩 | 118편 | `ai 코딩` 52개 |
| MCP | 76편 | `mcp 서버` 50개 |
| 온디바이스AI | 67편 | `로컬 llm` 69개 |
| RAG | 78편 | — |

**주제는 이미 맞았다. 포맷이 틀렸다.** 지금까지 이 주제들을 전부 "아키텍처
해부 / 딥다이브"로만 썼고, `요금제` `가격` `추천` `비교` `강의` 같은 상업
의도 포맷으로는 **단 한 번도 쓰지 않았다.** 검색 유입이 잡히는 90편이 전부
도구 고유명사인 것도 같은 이야기다 — 이미 이 영역에서 이길 힘이 있는데,
사람들이 돈 쓰기 직전에 치는 질의는 하나도 안 건드리고 있다.

주제를 통째로 바꾸는 것보다 **같은 주제를 다른 검색 의도로 다시 쓰는 게**
훨씬 빠르고 확실하다. 그래서 순서를 T1 → T2 → T3으로 잡는다.

---

## T1 — 즉시 수확 (기존 권위 × 상업 포맷)

이미 68~118편을 쓴 주제라 도메인 신호가 있다. 새 영역보다 순위가 빨리 붙는다.
**여기부터 시작한다.**

| 키워드 | 신뢰 | 포맷 | 메모 |
| --- | --- | --- | --- |
| 클로드 요금제 비교 / 가격 / 차이 / 추천 | G+N | ③가격 | 4개 변형 모두 최상위. 한 편으로 묶어 커버 가능 |
| 클로드 요금제 해지 / 변경 / 할인 | G+N | ③가격 | 위 글의 소제목으로 흡수 |
| 클로드 코드 가격 | G+N | ③가격 | ClaudeCode 68편의 권위를 그대로 씀 |
| 클로드 코드 사용법 | G+N | ①사용법 | |
| 클로드 코드 결제 안됨 / 결제 오류 | G | ④오류 | 경쟁 거의 없음. 롱테일 확보용 |
| 챗gpt 요금제 추천 / 차이 / 비교 | G+N | ③가격 | |
| 챗gpt 유료 무료 차이 | G | ③가격 | |
| 로컬 llm 추천 / 모델 비교 / 성능 비교 | G+N | ②비교 | 온디바이스AI 67편 보유 |
| 로컬 llm 사양 / 그래픽 카드 추천 | G+N | ②비교 | 하드웨어 제휴 여지 |
| 로컬 llm 설치 방법 / 구축 | G+N | ①사용법 | |
| mcp 서버 만들기 / 만드는 방법 | G+N | ①사용법 | MCP 76편 보유 |
| mcp 서버 추천 / 구축 방법 | G | ①사용법 | |
| rag 구축 방법 | G+N | ①사용법 | RAG 78편 보유 |

`클로드 요금제`만 변형 35개(양엔진 9개)다. 이 하나로 허브 페이지를 만들고
변형들을 소제목으로 흡수하는 게 가장 효율이 좋다.

## T2 — 강의 퍼널 (강의 사업 직결)

수집 결과에서 **강의, 교육, 자격증 계열이 239개** 나왔고 상위권을 독식했다.
강의를 파는 입장에서 이만한 키워드가 없다. 검색한 사람이 곧 잠재 수강생이다.

| 키워드 | 신뢰 | 메모 |
| --- | --- | --- |
| ai 강의 추천 | G+N | 수집 전체 최상위권 |
| ai 자격증 추천 / 종류 / 시험 / 취업 | G+N | 변형 17개 |
| 클로드 코드 강의 추천 | G+N | **T1 권위와 T2 수요가 겹치는 자리. 최우선.** |
| 클로드 사용법 강의 | G+N | |
| ai 코딩 강의 / ai 코딩 자격증 | G+N | |
| ai 업무 자동화 강의 / 교육 | G+N | Ring 1과 강의가 만나는 지점 |
| ai 데이터 분석 자격증 / 교육 | G+N | |
| ai 강의 무료 / ai 무료 강의 | G+N | 무료 검색층 → 리드마그넷으로 받는다 |
| ai 교육 학원 | G+N | 오프라인 의도. 출강 문의로 연결 |
| ai 상세페이지 강의 | G+N | Ring 2 + 강의 |

**주의**: `ai 자격증` 계열은 검색 수요는 크지만 직접 경험이 없으면 E-E-A-T가
약해진다. 자격증을 취득했거나 시험을 직접 본 게 아니라면 "종류 정리" 수준에서
멈추고, 경험을 쓸 수 있는 강의와 교육 키워드에 무게를 두는 편이 안전하다.

`클로드 코드 강의 추천`이 T1(권위 있음)과 T2(강의 수요)가 정확히 겹치는
유일한 자리다. **한 편만 쓴다면 이것부터.**

## T3 — 신규 링 확장

T1와 T2로 유입이 붙기 시작한 뒤에 간다. 여기는 도메인 권위가 없어 시간이 걸린다.

### Ring 1 — 직장인 실무

| 키워드 | 신뢰 | 변형 |
| --- | --- | --- |
| ai 회의록 추천 / 어플 / 작성 / 정리 / 녹음 | G+N | 15개 (양엔진 6) |
| ai 번역 추천 / 비교 / 번역기 추천 | G+N | 49개 (양엔진 9) |
| ai 번역 오류 | G+N | ④오류 포맷 |
| 챗gpt 프롬프트 만들기 / 설정 방법 | G+N | 23개 |
| ai ppt 만들기 | G+N | |
| 노션 ai 사용법 / 구글 제미나이 사용법 | G+N | |
| 챗gpt 엑셀 | G | 17개 변형이나 양엔진은 1개뿐 — 후순위 |

### Ring 2 — 자영업과 크리에이터

| 키워드 | 신뢰 | 변형 |
| --- | --- | --- |
| ai 상세페이지 만들기 / 추천 / 무료 / 프롬프트 / 자동화 | G+N | 18개 (양엔진 **8**) |
| ai 로고 만들기 무료 사이트 / 프롬프트 | G+N | |
| ai 자막 번역 / 생성 / 프로그램 / 사이트 | G+N | 28개 |
| ai 쇼츠 만들기 | G+N | |

`ai 상세페이지`는 18개 변형 중 8개가 양엔진 공통이다. 밀도로 보면 Ring 2에서
가장 확실한 클러스터다. `ai 상세페이지 부업`(네이버)도 잡혀 상업 의도가 짙다.

### Ring 3 — 학생과 취준생

| 키워드 | 신뢰 | 변형 |
| --- | --- | --- |
| ai 자소서 추천 / 첨삭 / 검사기 / 작성 | G+N | 37개 (양엔진 8) |
| 챗gpt 자소서 프롬프트 | G+N | Ring 1과 교차 |

시즌을 심하게 타므로 채용 시즌 전에 미리 써두고 매년 갱신하는 방식으로만.

## 실행 순서

1. **클로드 코드 강의 추천** — T1 권위 × T2 수요 교차점. 첫 글.
2. **클로드 요금제 총정리** — 변형 35개를 허브 하나로 흡수.
3. **로컬 LLM 추천 / 사양 비교** — 온디바이스AI 67편 권위 활용.
4. **MCP 서버 만들기** — 76편 권위 활용, `①사용법` 포맷 첫 시도.
5. **AI 강의 / 자격증 종류 정리** — 강의 퍼널 진입점.
6. 여기까지 유입이 붙으면 T3(회의록 → 상세페이지 → 자소서) 순서로 확장.

각 글은 `automation/prompt_config.json`에 넣어둔 규칙(첫 문장 40~60자 직답,
날짜 명시, 비교는 표, "그래서 내 업무에는" 섹션)을 그대로 적용한다.

## 갱신

```bash
python automation/harvest_keywords.py --depth 1 --out automation/data/keyword_bank.json
```

분기 1회면 충분하다. Search Console이 연결되면(`automation/search_console.py`)
자동완성 추정 대신 실제 노출과 순위 데이터로 이 문서를 대체할 것.
